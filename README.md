# ADUN Dinner & Awards Night Ticketing

A lightweight event-ticketing website created for a university dinner and awards event. The project includes ticket pages and QR-code-based ticket verification.

## Project Overview

The site is intended to support event entry by providing a digital ticket and a verification page for checking tickets at the door.

## Features

- Digital ticket presentation
- QR-code-based ticket verification
- Ticket detail page
- Browser-based interface

## Technology

- HTML
- CSS
- JavaScript
- QR-code API/integration

## Live Demo

[Open the deployed ticketing site](https://devobichinaka.github.io/dinner/)

## Repository

The implementation is a small static web project. Open `index.html` in a browser for local inspection, or serve the project with any simple static HTTP server.

## Notes

This repository documents a project built for a specific university event. It should not be treated as a general-purpose ticketing platform without further work on authentication, ticket lifecycle management, duplicate-use prevention, operational monitoring, and security review.
